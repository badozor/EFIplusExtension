efitools - changes
==================

Version 1.3 (30/10/2026)
------------------------

Bug fix
- internal/efiminus.R, RecodeNameOutputDiad(): the output columns
  Hist.ric.diadromous and Present.ric.diadromous were swapped in 1.2
  (Hist.ric.diadromous received the present richness, Present.ric.diadromous
  the historical richness). Ids.ric.diadromous (= present / historical) was
  already correct and is unchanged. Only these two columns differ from 1.2.

Compatibility (R >= 4, UTF-8, Rscript); the computation is unchanged
- main.R, maindiad.R: 'directory' is read from the environment variable
  EFI_DIR (default: current working directory) instead of a hard-coded path.
- main.R, maindiad.R: arguments read with commandArgs(trailingOnly = TRUE),
  so the scripts work with Rscript as well as with R --args ... < main.R.
- main.R, maindiad.R: absolute paths accepted for input, output and
  diadromous files; relative names are still looked up in input/ and output/.
- main.R, maindiad.R: comment.char = "£" / "¤" replaced by comment.char = "".
  In a UTF-8 locale these characters take two bytes and R 4.x refuses them.
- All text files re-encoded from ISO-8859-1 to UTF-8, Unix line endings.
- internal/efiminus.R, ClassifIDScoring(): returns NA when the class limits
  are missing. stdpacklength has no 'qclass': R <= 4.5 returned NA for
  cut(x, NULL), R >= 4.6 stops with "invalid 'breaks' argument". These
  per-metric classes were experimental work and are not in the final output.
- internal/diadromousplus.txt: non-breaking space (U+00A0) in the header
  "Alosa immaculata historic/present" replaced by a normal space. In a
  latin-1 locale (Windows, R < 4.2) the UTF-8 bytes changed the column name
  and maindiad.R stopped with "undefined columns selected".

Not changed (known issue)
- internal/efiminus.R, commentDate(): the test 'month > 11 & month < 8' is
  never true, so Comments.date is always "Nothing to report".

Usage
  Rscript --vanilla main.R input.txt output.txt
  Rscript --vanilla maindiad.R input.txt output.txt diadromous.txt
Run from the efitools-1.3 folder, or set EFI_DIR to that folder.
Argument order of maindiad.R: input, output, diadromous (as in 1.2).

Tested on Linux with R 4.3.3, 4.5.3 and 4.6.2 (5 invented samples, with and
without diadromous data): identical output. Not re-tested with R 2.8.1.
